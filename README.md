# Tri Perspective Knowledge Graph - Demo

Prereqs :
(Optional but recommended : activate virtual environment in the folder
python3 -m venv venv
source venv/activate/bin)
1. Install dependencies from requirements.py
    pip install -r requirements.txt
2. Download spacy library
    python -m spacy download en_core_web_sm


How to use :
1. Add desired sample_paragraph in main.py
2. run main.py
python main.py
3. run tpkg/visualize.py
python tpkg/visualize.py
4. Open the kg_visualizer.html file and enjoy
